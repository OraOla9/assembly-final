# 微机接口汇编实训：三位倒计时器

> 8086 汇编实现的三位数倒计时，含 8259/8255 中断与数码管显示

## 项目简介

使用 8086 汇编编写的倒计时程序：输入三位数字后逐次减一，通过 8259A 中断控制器与 8255 并行接口驱动数码管显示，支持 `s` 暂停、`d` 继续、空格退出。源码中的班级与学号标识已移除。

## 技术栈

- 8086 汇编
- MASM / DOSBox
- 8259A PIC
- 8255 PPI
- 七段数码管

## 快速开始

1. 在 DOSBox 中挂载 MASM 工具链与本目录。
2. `masm main.asm;` → `link main.obj;`
3. 运行 `main.exe`，按提示输入三位数字。

## 配置说明

需要在 DOSBox / 实机 DOS 环境下运行；源码内端口地址按实验箱配置，可按需调整。
